# Spark Default Community Health Files

This public `.github` repository provides fallback community-health files for `vibeforge1111` repositories that do not define their own local files.

The default pull request template points competition contributors to:

- https://compete.sparkswarm.ai/docs/submission-spec.md
- https://compete.sparkswarm.ai/schemas/spark-compete-hotfix-v1.json
- https://compete.sparkswarm.ai/examples/spark-compete-hotfix.valid.json

Repositories with their own `PULL_REQUEST_TEMPLATE.md` continue to use their local template.
